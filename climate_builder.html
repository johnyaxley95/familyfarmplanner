Climate table builder

One-time tool. It fetches each town's monthly climate normal (FAO-56 reference ETo + rainfall) from SILO, then prints a CLIMATE_DB block to paste back for inlining into the planner. After that the planner needs no live fetch.

Must be opened from an https address (e.g. your GitHub Pages URL) — SILO blocks cross-origin requests from a local file:// page. It pulls a 20-year daily series (2005–2024) per town, so the full run downloads ~30 MB across ~79 sequential requests and takes a few minutes. Leave the tab open.
